# Guimo — Landing Page (Clean Look)

Sitio web oficial de **Guimo** (*"Ligero, seguro y contigo"*): el asiento modular y adaptable que acompaña el crecimiento de tu hijx (diseñado para niños con PCI de 3 a 11 años).

## ✨ Características del Diseño (Clean Look)
- **Estética limpia y luminosa**: Fondos claros (`#FAFBFD` y `#FFFFFF`) con amplio espacio en blanco, tarjetas con bordes suaves y sombras sutiles.
- **Identidad cromática Guimo**: Acentos refinados en azul cielo (`#67B7E1`), rosa coral (`#F06E9C`), verde lima (`#9ACA3C`), naranja (`#F59223`) y amarillo (`#F9C823`).
- **Secciones incluidas**:
  1. **Header & Navegación**: Menú limpio con indicadores de color sutiles y CTA directo.
  2. **Hero Section**: Presentación del asiento modular Guimo con indicadores clave de edad (3 a 11 años), soporte lumbar clínico y adaptabilidad.
  3. **Impacto Social (4x1)**: Banner limpio destacando el programa *"Por cada 4 respaldos vendidos, donamos 1 a una familia que lo necesita"* con las ilustraciones modulares de Guimo.
  4. **Testimonios**: Carrusel interactivo con historias reales de familias (ej. Lili Arzate y Hasen).
  5. **Buscador de Distribuidores**: Filtro interactivo por ciudad o código postal (ej. Querétaro) con tarjetas de especialistas y mapa interactivo.
  6. **Footer**: Enlaces rápidos, redes sociales, contacto y aviso de privacidad.

## 🚀 Estructura del Proyecto
```text
guimo-landing/
├── index.html          # Estructura principal semántica
├── css/
│   └── styles.css      # Sistema de diseño Clean Look (Variables CSS, Grid/Flexbox, Responsive)
├── js/
│   └── main.js         # Interactividad: carrusel de testimonios, buscador de distribuidores y menú móvil
└── assets/
    └── images/         # Ilustraciones SVG y recursos visuales de Guimo
```

## 💻 Cómo ejecutar localmente
Simplemente abre `index.html` en tu navegador o sirve la carpeta con cualquier servidor estático:
```bash
npx serve .
```
